## Overview

Designed a cross-device viewing experience for a sports live streaming platform — integrating live broadcast, real-time chat, scores, and interactive features while keeping a clear visual hierarchy and smooth operation in high information-density contexts.

---

## Scope of Work

UX Flow · Information Architecture · Wireframe · UI Design · Responsive Design · Interaction Design · Design Handoff

---

## The Challenge

A sports live streaming platform has to support video viewing, real-time interaction, match information, and backend management tools all at once. While watching a match, users need to quickly take in the score, interaction messages, and live content; meanwhile, streamers and assistants need to manage the chat room, control interactive content, and handle real-time situations throughout the broadcast.

The core challenge of this project was this: how to integrate a large volume of information and operational features into a single interface without disrupting the viewing experience — while keeping that experience clear, stable, and easy to operate on both desktop and mobile.

### Core Pain Points

- Real-time chat, gifting interactions, and match information can easily scatter the viewer's focus and undermine the immersion of watching the game.
- Streamers and assistants need to handle management, interaction, and control tasks simultaneously during a broadcast, so the interface must offer a clear operational hierarchy and fault-tolerant design.
- The desktop version needs to integrate video, chat, match information, and interaction modules without becoming visually overcrowded.
- Mobile screens have limited space, calling for a more effective way to switch between watching and interacting.

---

## Design Process

I led the overall UI/UX design — covering use-case mapping, information architecture, desktop and mobile interface design, interaction flows, component planning, and design handoff. Throughout the process, I paid particular attention to the information hierarchy of real-time interaction interfaces, the differences in role-based permissions, and consistency across devices.

---

## Design Strategy

### A Modular Information Architecture

I separated the live video, chat room, match information, and interaction features into independent modules, avoiding stacking all content within a single visual area. On desktop, a modular layout keeps the video as the primary visual focus while letting users quickly check the chat room and match status.

This keeps the different information blocks independent yet working in concert on the same page, lowering the cost of switching between watching and looking things up.

### Distinguishing Streamer, Assistant & Member Needs

Each role has different tasks within the live room, so I designed corresponding permissions and interface layers for each one. Regular members focus on watching, chatting, and interacting; streamers and assistants need faster access to pinning messages, muting, managing interactions, and keeping the broadcast in order.

Through role-oriented design, every user only sees the controls relevant to their own tasks, avoiding unnecessary feature clutter.

### Mechanics That Build Stickiness

To boost user stickiness, I designed mechanics that pair real-time interaction with longer-term incentives: streamer gifting turns passive viewing into two-way interaction, while daily check-ins and task rewards make return visits rewarding — building habits and keeping the platform active outside match hours.

---

## Impact

- Established a clearer information hierarchy for the live room, letting viewing, interaction, and match information coexist within a single interface.
- Through role-oriented design, streamers, assistants, and regular members can each quickly find the features they need for their tasks.
- The mobile interaction flow better fits the viewing context, reducing the disruption that chat and interactive content cause to the live feed.
- The modular architecture improved consistency for later feature expansion and cross-device design.
