## The Challenge

Inplay Matrix's esports gaming backoffice is a complex system serving multiple departments simultaneously — business analysts, operations staff, and customer service teams. The existing system had scattered functionality and inconsistent interaction logic, leading to low team efficiency.

### Core Pain Points

- 7+ departments using different operational logic, creating extremely high learning costs
- Conflicting demands between real-time data monitoring and page load speeds
- No unified design language — every new feature felt like "patching" the system

---

## Design Strategy

### 1. Stakeholder Interviews & Role Modeling

Collaborated deeply with BAs and PMs to define 5 core user roles. Built User Journey Maps for each role to identify "breakpoints" and "redundant actions" in operational workflows.

### 2. Modular Design System

Built an extensible Component Library and Design Guideline with **60+ UI components** and a Token System (color, spacing, typography specifications) to ensure visual and interaction consistency across all functional modules.

### 3. Progressive Migration Strategy

Considering the team's dependence on the legacy system, I designed a "progressive redesign" roadmap — unifying visual style first, then gradually optimizing workflows to avoid the adaptation costs of a one-time overhaul.

---

## Key Design Decision

For the data dashboard design, I faced a critical choice: **"Global Overview"** vs. **"Role-Customized"** Dashboard.

I chose the latter — each role sees an information layout optimized for their specific tasks upon login, rather than a single massive dashboard containing all data.

This decision reduced the average time to "find needed information" from **30 seconds to 5 seconds**.

---

## Impact

- Component Library with 60+ reusable components, improving design efficiency by 50%
- New employee training time reduced from 2 weeks to 3 days
- System received highly positive internal team reviews
